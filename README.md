# Yolg'izlik Chat — Test versiya

**Ro'yxatdan o'tish yo'q.**  
Havola yaratasiz → do'stingizga yuborasiz → ikkalangiz real vaqtda yozishasiz + rasm yuborasiz.

## Ishlatish

### 1. O'rnatish
```bash
cd backend
npm install
npm start
```

Brauzerda: **http://localhost:3000**

### 2. Qanday ishlaydi
1. "Xona yaratish + Havola olish" bosasiz
2. Havola avtomatik chiqadi (URL o'zgaradi)
3. **🔗** tugmasini bosib havolani nusxalaysiz
4. Do'stingizga yuborasiz
5. Do'stingiz havolani ochadi → bir xonaga tushasizlar
6. Yozishasiz, rasm yuborasiz

### 3. Do'stingiz boshqa joyda bo'lsa
Backend ni internetga chiqaring (Render / Railway) — keyin havola butun dunyoda ishlaydi.

## Texnologiyalar
- Backend: Node.js + Express + Socket.io
- Frontend: HTML + CSS + JS
- Rasm: Multer
